# portfolio

Portfolio Patryka Dzieży w wersji polskiej i angielskiej: aplikacje webowe,
mobilne i desktopowe oraz automatyzacje AI.

- Wersja polska: `index.html`
- Wersja angielska: `en/index.html`
- Wspólne style: `styles.css`
- Strona: https://patrykdzieza.pl/

## Podgląd lokalny

```sh
python -m http.server 8080
```

Otwórz http://localhost:8080/ lub http://localhost:8080/en/.

Publikacja przez GitHub Pages z gałęzi `main`. Aktualizuj obie wersje językowe,
statusy projektów i datę aktualizacji razem. Plik `CNAME` wskazuje domenę strony.
